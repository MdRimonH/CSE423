# CSE423
This is the Computer Graphics course at BRAC University for the Fall 2025 semester.

Description:
Shape drawing algorithms: Line, Circle, Ellipse, 8-way symmetry; Clipping algorithms: Cohen-Sutherland, Cyrus-Beck; Transformation (2D/3D): Translation, Scaling, Rotation, Reflection, Shear, transformation matrices, types; Projection: 3D in 2D space; Color models: RGB, CMYK, HSV; Illumination and Shading.


Course Name: Computer Graphics [CSE423]

Semester: Fall 2025

Course Instructors: Mahir Labib Dihan [MLDH], Anika Ahmed [ANKH]
